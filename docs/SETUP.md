# Week 1 hosted-service setup

Local development does not require secrets. The Week 1 exit gate additionally requires development and production Convex deployments, two Vercel projects, and one custom Bright Data Scraper Studio Browser collector.

Never paste credentials into issues, commits, screenshots, or collector source. Add them only to local `.env.local` files and the corresponding hosted environment-variable settings.

Resource names and exact account steps are tracked in the phase handoff so they can be completed without inventing deployment evidence.
