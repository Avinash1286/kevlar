# Kevlar v1.0.1 release scope

This release freezes the complete twelve-phase reference platform around one fully rehearsed product-pricing source and a controlled multi-source intelligence proof. It includes the repair-certification kernel, Bright Data acquisition, reviewed mappings and identity, bitemporal facts, semantic events, evidence bundles, REST/webhook/SDK/MCP delivery, tenant RBAC, operations controls, recovery manifests, retention/deletion, and verified-event AI routing.

The public production surface is the Vercel-hosted operator and developer application. Convex backend proofs were deployed only to the named development deployment documented in the release evidence; promotion to another Convex account or production deployment is outside this release.

The release deliberately does not claim population-level accuracy, autonomous high-impact approval, physical deletion of immutable trust history, or proven disaster recovery. It proves a source snapshot export plus same-project manifest/query verification; an isolated import drill remains open. See [limitations](LIMITATIONS.md) and [recovery](RECOVERY.md) for the exact boundaries.

This patch release adds comprehensive tenant publication boundaries, release evidence, and submission packaging after the immutable `v1.0.0` baseline. Changes after the `v1.0.1` tag require a new version and fresh measured artifacts. Benchmark numbers must come from committed raw results; no placeholder or projected measurement is a release claim.
