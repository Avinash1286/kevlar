The authoritative dependency graph and exact resolved versions are in [`pnpm-lock.yaml`](pnpm-lock.yaml). Maintainers can audit the installed license declarations with:

```bash
pnpm licenses list --prod
pnpm licenses list --dev
```

Transitive packages retain their own notices and licenses in the installed package distribution.

## Fonts and media

The applications load [Inter](https://github.com/rsms/inter), [DM Mono](https://github.com/googlefonts/dm-mono), and [Newsreader](https://github.com/productiontype/Newsreader) through `next/font/google`. Each upstream project distributes its font under the SIL Open Font License 1.1; `next/font` self-hosts the build output.

The two tracked WebM files under `artifacts/demo/` are recordings generated by `scripts/record-release-demos.ts` from the deployed Kevlar interfaces. No separately sourced image, icon, audio, or stock-video file is tracked in the repository.
