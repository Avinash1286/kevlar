# Convex boundary

Week 1 defines the `projects`, `collectors`, `runs`, `rows`, `evidence`, and `auditEvents` tables. Hosted functions are generated only after `pnpm convex:dev` links the local checkout to a Convex development deployment.

Convex functions authenticate, authorize, load state, call pure modules, persist transitions, schedule durable work, and append audit events. Trust algorithms belong in `packages/*`.
